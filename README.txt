Сервисник — законченная демонстрация главной страницы

ЗАПУСК
Откройте index.html в современном браузере. Сборка и npm не нужны.
Либо из папки проекта запустите: python -m http.server 8765
Адрес: http://localhost:8765/

СОСТАВ
Первые три утверждённые секции сохранены. Добавлены каталог техники,
отзывы, преимущества, команда, руководство, форма заявки, статьи,
таблица восьми адресов с фильтрами, встроенная карта и полный футер.
Новые стили и поведение: homepage.css и homepage.js.
Все фотографии новых разделов — с оригинального servicenik.ru,
локальные оптимизированные копии в assets/original/.

ДЕМОНСТРАЦИОННЫЕ ДЕЙСТВИЯ
Форма проверяет поля, но не отправляет данные. После заполнения
открываются реальные контакты выбранного города.
Обращения руководству ведут к исходной форме и email сервиса.
Отзывы открывают исходные площадки. Видео использует оригинальный
MP4 с сайта; карта загружается автоматически при просмотре адресов.
Интернет нужен для внешних страниц, видео и карты.
MAX в утверждённой шапке остаётся недоступным: ссылка не предоставлена.

ОПТИМИЗИРОВАННАЯ СБОРКА (07.11.2026)
Сайт остаётся статическим: для просмотра npm не нужен.
В index.html подключены site.min.css и site.min.js; Choices остаётся
отдельной локальной библиотекой. Исходные CSS и JS сохранены.

После правки исходных CSS/JS:
1. Один раз установите средства сборки: npm ci
2. Обновите итоговые файлы: npm run build
Порядок и список исходников заданы в site-assets.json.
Сборка автоматически обновляет версии ссылок, чтобы браузер не показывал старый код.
Для публикации нужны index.html, site.min.css, site.min.js и assets/.
Node.js нужен только для пересборки, но не для работы сайта.

Основные PNG-иллюстрации и логотипы отзывов перекодированы в WebP
без потери пикселей; PNG-исходники оставлены для последующих правок.
Результаты и проверки: docs/optimization-report.json и docs/optimization-qa.md.
